Tips & Info

🖼️
Multimodal Support
Image input requires a vision-capable model (e.g. hunyuan-turbo-vision). Standard text models return errors for images.
🔄
Streaming
The proxy supports SSE streaming. If you see Reconnecting, the upstream may have rejected the request or timed out.
📊
Token Tracking
Token usage is tracked per-model. Use the time range buttons to filter by today, this week, or all time.
⚡
Quick Switch
Click the model name in System Status or use the dropdown in the header to quickly switch models.
🔒
Direct HTTPS
All requests are forwarded directly to providers via HTTPS. No third-party relay involved.
📡
API Compatible
Fully compatible with OpenAI Responses API. Use any OpenAI SDK client and point it to this proxy.
